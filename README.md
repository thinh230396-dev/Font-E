# SalonSys Admin

Dashboard Superadmin cho hệ thống SaaS quản lý chuỗi salon. Ứng dụng hiện là frontend React/Vite; dữ liệu nghiệp vụ được lưu trong `localStorage` của trình duyệt và chưa kết nối backend.

## Chạy tại máy

Yêu cầu Node.js và npm.

```bash
npm install
npm run dev
```

Mặc định Vite chạy tại `http://localhost:3000`. Phiên bản hiện tại không yêu cầu biến môi trường.

## Kiểm tra

```bash
npm run lint
npm run build
```
